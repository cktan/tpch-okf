## Knowledge Management (OKF)
- This project uses the Open Knowledge Format (OKF) for documentation
  and context.
- Before starting any task, refactoring, or generating code, you
  **must** read the main OKF index file `tpch/index.md` and the skill
  in `.agents/skills/tpch_schema/SKILL.md`.
- Follow the relevant OKF markdown links to gather full context on the
  specific module or architecture you are working on.
- If you introduce new core concepts or architectural patterns, update
  or create the corresponding OKF files and link them to the index.
